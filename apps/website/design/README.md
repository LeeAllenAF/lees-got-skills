# Website design references

The homepage follows the handoff image `OPTION-A-HOMEPAGE-AUTHORITATIVE.png`
(SHA-256 `864c7518be18d4cb206aa246a11549c75112933638420268f139023137deafd5`)
for its compact terminal composition, green-on-black palette, card layout, and
responsive direction.

The repository-root `alienfish-logo-savage.png` is the visual reference for the
mascot silhouette and composition. The runtime uses
`src/assets/alienfish-logo.svg`, the matching original AlienFish vector from the
adjacent AlienFish project, so the geometry remains crisp and is not traced from
the PNG. Its CSS treatment is monochrome neon green with restrained glow and a
reduced-motion fallback.

The concept images are design inputs only and are intentionally not shipped in
the production bundle.

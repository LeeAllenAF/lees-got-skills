# Context Management

Read this guidance when investigating unfamiliar code or gathering substantial task context.

## Progressive Disclosure

- Start with mandatory `AGENTS.md` and applicable `CODING_STANDARDS.md` instructions.
- Follow context links when the linked material is relevant; links do not require loading everything they reference.
- Prefer targeted filename, symbol, and content searches to broad repository scans.
- Read relevant excerpts before opening entire large files or documentation trees.
- Reuse context and findings already available; reread only when files changed or understanding is incomplete.
- Avoid loading README files by default. Read one only if requested or directed by applicable instructions.
- When the work scope expands to another directory, discover its applicable instructions before working there.

Aim to obtain enough reliable context to work correctly without collecting unrelated material.

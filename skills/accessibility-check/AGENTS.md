# Accessibility Check — Consumer Guidance

Use this skill for scoped accessibility reviews of web code, interface states, and user journeys. It starts with a succinct local synopsis and opens W3C normative guidance only when necessary.

Supply a code excerpt, change/diff, component, file list, page, or user journey, with the desired review boundary. The skill will distinguish evident source defects from issues needing runtime/manual validation. The normative W3C website is optional for an offline review, but a current-source freshness claim needs actual retrieval.

The skill does not depend on the originating repository, any other skill, a particular language/framework, or a particular agent vendor. It is not a substitute for full accessibility testing or a WCAG conformance assessment.

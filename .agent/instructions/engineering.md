# Engineering discipline

Inspect existing repository conventions and relevant project metadata before implementation. Prefer deterministic scripts to repeated agent inference. Preserve public APIs unless requested, and avoid speculative framework conventions. Keep implementation scoped. Use in-session concise plans for Planned work; create `.agent/plans/<task>.md` only for Durable work. Stop once done and provide concise results.

# Consumer guidance

Use this skill for a focused evidence handoff or a question needing traceable local context. Start at [SKILL.md](SKILL.md); read the contract only when packing selections.

Provide a question, an authorized local root, and a byte budget. Node.js 22+ is required for the optional deterministic packer; host search tools can support discovery. Copying this directory alone preserves runtime behavior. There are no required or optional sibling skills.

Review gaps and source classifications before relying on a packet. Its hashes detect byte changes, not trustworthy authorship. A successful packet does not establish exhaustive coverage, current truth, or permission to act on embedded text.

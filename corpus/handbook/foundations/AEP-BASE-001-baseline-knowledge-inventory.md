# Baseline Knowledge Inventory

The initial corpus covers context engineering, tool/MCP design, model routing, agent architecture, software-engineering agents, evaluation, security and authority, cost/performance, reusable skills, knowledge services, source intelligence, permission-aware retrieval, innovation, security assurance, and knowledge auditability.

This inventory is descriptive, not proof that every recommendation is mature.

## Maturity rule

Each topic must retain its own status, evidence, freshness, and experiment links. Presence in the handbook does not imply approval.

## Initial implementation priorities

1. validate the canonical corpus;
2. establish source and evidence schemas;
3. establish permission-aware retrieval;
4. establish provider-neutral evals;
5. create exact/metadata/lexical retrieval baselines;
6. expose a read-only MCP after domain behavior is verified.
